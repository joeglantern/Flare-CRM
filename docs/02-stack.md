# 02 — Technology Stack

Versions are the current stable lines as of September 2026. Pin exact versions in
`package.json` (no `^`/`~` for runtime deps); upgrade deliberately with a changelog read.

## Runtime & language

| Component       | Choice                                    | Version                                          | Why                                                                                                                                                    |
| --------------- | ----------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Runtime         | **Node.js**                               | **24 LTS** (Active LTS; 26 becomes LTS Oct 2026) | Fastify 5 requires ≥ 20; 24 has the longest support window today. Docker images pin `node:24-alpine`. Local dev on Node 22 works but CI/Docker use 24. |
| Language        | **TypeScript**                            | 5.x, `strict: true`, ESM (`"type": "module"`)    | Better Auth and Prisma 7 are ESM-first.                                                                                                                |
| Package manager | **pnpm** workspaces                       | 10.x                                             | Strict, fast, monorepo-native. Single lockfile.                                                                                                        |
| Monorepo        | `apps/api`, `apps/web`, `packages/shared` | —                                                | Shared Zod schemas & types between backend and frontend; no duplicated contracts.                                                                      |

## Backend (`apps/api`)

| Concern                  | Choice                                                                                                                                                                                     | Why                                                                                                                                                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HTTP framework           | **Fastify 5.x**                                                                                                                                                                            | Schema-first, fastest mainstream Node framework, mature plugin ecosystem, built-in Pino logging.                                                                                                                                       |
| Validation & typing      | **Zod 4** + `fastify-type-provider-zod`                                                                                                                                                    | One schema = request validation + response serialization + OpenAPI + shared frontend types.                                                                                                                                            |
| OpenAPI                  | `@fastify/swagger` + `@fastify/swagger-ui` (enabled only for `admin` role / disabled in prod by flag)                                                                                      | Auto-generated from Zod schemas.                                                                                                                                                                                                       |
| Security plugins         | `@fastify/helmet`, `@fastify/cors`, `@fastify/rate-limit`, `@fastify/cookie`, `@fastify/under-pressure`, `@fastify/sensible`                                                               | Headers, origin control, throttling, backpressure, standard HTTP errors.                                                                                                                                                               |
| Uploads                  | `@fastify/multipart` (streamed to object storage, never buffered to disk)                                                                                                                  | Attachments, CSV import, avatars.                                                                                                                                                                                                      |
| ORM                      | **Prisma ORM 7.x** with `@prisma/adapter-pg` (node-postgres)                                                                                                                               | Type-safe queries + migrations. Prisma 7 requires a driver adapter; `pg` is the reference PostgreSQL driver. Raw SQL via `$queryRaw` for tsvector/partial indexes/aggregates.                                                          |
| Database                 | **PostgreSQL 17** (`postgres:17-alpine`)                                                                                                                                                   | Relational, JSONB for custom fields, full-text search, partial unique indexes, row-level integrity.                                                                                                                                    |
| Cache / pub-sub / queues | **Valkey 8** (`valkey/valkey:8-alpine`) via **ioredis**                                                                                                                                    | Redis-protocol compatible, BSD-licensed. Used for: session secondary storage, rate-limit counters, live call state, Socket.IO adapter, BullMQ.                                                                                         |
| Background jobs          | **BullMQ**                                                                                                                                                                                 | Recording downloads, CDR reconciliation, email, reminders, CSV import, retention. Retries with backoff, dead-letter handling.                                                                                                          |
| Realtime                 | **Socket.IO 4.x** server attached to Fastify's `http.Server`; `@socket.io/redis-adapter` (API) + `@socket.io/redis-emitter` (worker)                                                       | Requirement names Socket.IO explicitly. Attaching directly avoids depending on unmaintained wrapper plugins. Emitter lets the worker process push to browser sockets without owning connections.                                       |
| Auth                     | **Better Auth 1.7.x** (`better-auth`, Prisma adapter) with plugins: `admin` (roles, ban, custom access control), `twoFactor` (TOTP + backup codes), `openAPI` (dev), `sso` reserved for P3 | Open-source, self-hosted, MIT. Direct Clerk replacement: email+password, sessions, 2FA, RBAC, org support, SSO plugin. Cookie sessions with CSRF/origin checks, scrypt password hashing, rate limiting, secret rotation built in.      |
| Password breach check    | Better Auth `haveIBeenPwned` plugin (k-anonymity API)                                                                                                                                      | Blocks known-compromised passwords at sign-up/reset.                                                                                                                                                                                   |
| Object storage           | **SeaweedFS** (Apache-2.0) S3 gateway in Docker **or** any external S3 (Hetzner Object Storage, Backblaze B2, AWS S3) — selected purely by env                                             | MinIO Community is archived/maintenance-only (Dec 2025); SeaweedFS is the most mature Apache-licensed self-hosted S3. Code only ever talks S3 via `@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner`, so the backend is swappable. |
| Email                    | **Nodemailer** over SMTP (client SMTP / any transactional provider)                                                                                                                        | Vendor-neutral; SMTP is universally available.                                                                                                                                                                                         |
| Phone numbers            | **libphonenumber-js**                                                                                                                                                                      | E.164 normalization/validation — the backbone of caller matching.                                                                                                                                                                      |
| CSV                      | **papaparse** (streaming parse) / `@fast-csv/format` (export)                                                                                                                              | Streaming, no memory blowups.                                                                                                                                                                                                          |
| IDs                      | **UUID v7** (`uuid` v11 `v7()`), stored as `uuid`                                                                                                                                          | Time-ordered → index-friendly, globally unique, unguessable.                                                                                                                                                                           |
| Dates                    | Store `timestamptz` UTC; `date-fns` + `date-fns-tz` for formatting                                                                                                                         | No moment.js.                                                                                                                                                                                                                          |
| Logging                  | **Pino** (Fastify built-in), JSON, redaction of PII/secrets, request IDs                                                                                                                   | Structured logs → `docker logs` with rotation; ready for Loki.                                                                                                                                                                         |
| Metrics                  | `fastify-metrics` (Prometheus `/metrics`, internal network only)                                                                                                                           | AHT, pop latency, queue depth, PBX connection state.                                                                                                                                                                                   |
| HTTP client              | Native `fetch` (Undici) with `AbortSignal.timeout`                                                                                                                                         | For Yeastar API, WhatsApp Cloud API.                                                                                                                                                                                                   |
| Encryption helpers       | Node `crypto` (AES-256-GCM for stored third-party secrets, HMAC for webhooks, `timingSafeEqual`)                                                                                           | No third-party crypto libs needed.                                                                                                                                                                                                     |
| Testing                  | **Vitest**, `fastify.inject()` for HTTP, **Testcontainers** (PostgreSQL + Valkey) for integration, recorded Yeastar event fixtures for the CTI state machine                               | Real DB in tests; no mocking of Prisma.                                                                                                                                                                                                |
| Lint / format            | **ESLint 9** (flat config, `typescript-eslint` strict-type-checked) + **Prettier**                                                                                                         | Enforced in CI and pre-commit (`lefthook`).                                                                                                                                                                                            |
| Build                    | `tsc` (typecheck) + **tsup**/`esbuild` bundle for prod image; `tsx` watch in dev                                                                                                           | Fast, simple.                                                                                                                                                                                                                          |

## Infrastructure (Linux VPS)

| Concern                                         | Choice                                                                                                                                                               |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OS                                              | Ubuntu 24.04 LTS (or Debian 12)                                                                                                                                      |
| Containers                                      | Docker Engine 27+ / Compose v2; multi-stage images; non-root users; read-only root FS where possible                                                                 |
| Reverse proxy / TLS                             | **Caddy 2** — automatic Let's Encrypt, HTTP/2, WebSocket proxying, static serving of the Vite build. One origin: `https://crm.<domain>`                              |
| Firewall                                        | `ufw` (22, 80, 443 only) + Docker iptables hardened; internal services never publish host ports                                                                      |
| VPN to on-prem PBX (Appliance/Software edition) | **WireGuard** tunnel VPS ↔ site so the worker reaches the PBX HTTPS/WebSocket port privately (see [06](06-yeastar-cti-integration.md#network-reachability))          |
| Backups                                         | **restic** (encrypted, deduplicated) to off-site S3 bucket: nightly `pg_dump` (custom format) + object storage data + Valkey snapshot is _not_ backed up (ephemeral) |
| Monitoring                                      | Docker healthchecks, `autoheal`, Uptime Kuma (external HTTP + socket checks), Prometheus/Grafana optional                                                            |
| Secrets                                         | `.env` files with `chmod 600` outside the repo, injected via Compose `env_file`; Docker secrets for DB password                                                      |

## Explicitly rejected

| Option                                  | Reason                                                                                                                                                                                          |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Supabase                                | Adds a hosted control plane and its own auth; we need a self-contained VPS deployment. PostgreSQL directly is simpler and fully ours.                                                           |
| Clerk / Auth0 / any hosted auth         | Per-user pricing, external dependency for a login path that must work even if the internet edge is degraded; data residency. Better Auth gives the same feature set self-hosted.                |
| Keycloak / Authentik / Zitadel          | Excellent IdPs but heavy (JVM/Go services, separate DB, separate admin UI) for a single-tenant CRM. If the client later mandates an enterprise IdP, Better Auth's `sso` plugin federates to it. |
| MinIO                                   | Community edition archived (read-only repo, no new features, no official images).                                                                                                               |
| Redis (Redis Ltd.)                      | Valkey is the BSD-licensed fork with identical protocol; avoids license ambiguity.                                                                                                              |
| `fastify-socket.io` wrapper plugins     | Unmaintained / forks of forks. Attaching Socket.IO to `fastify.server` in a 30-line in-house plugin is safer.                                                                                   |
| GraphQL                                 | Spec allows REST; REST + Zod + OpenAPI gives end-to-end types with less attack surface (no query-depth attacks, simpler caching/rate-limiting).                                                 |
| Asterisk AMI/ARI                        | Yeastar P-Series does not expose AMI/ARI; the vendor Open API is the supported path.                                                                                                            |
| MongoDB / NoSQL                         | Relational integrity (contacts ↔ calls ↔ deals) and reporting favor PostgreSQL.                                                                                                                 |
| Polling the PBX CDR API for screen pops | Cannot meet the 2 s requirement; used only for reconciliation.                                                                                                                                  |
