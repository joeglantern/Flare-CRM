# 16 — Open Questions & Working Assumptions

Spec §10 questions plus ones raised by the design. We build against the **default** until the
client answers; each default is an env/setting switch so answers do not cause rework.

| #   | Question                                          | Default we build against                                                                                                                                  | Switch                                              |
| --- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
