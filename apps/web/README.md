# @crm/web

Flare CRM web client. Vite 8, React 19, TanStack Router (file based) and Query, Tailwind v4 with the tokens from `docs/18`, Better Auth client, Socket.IO client typed from `@crm/shared`.

## Run

```
pnpm docker:dev            # postgres, valkey, seaweedfs, mailpit
pnpm dev                   # api on 127.0.0.1:4000
pnpm dev:web               # web on 127.0.0.1:5173, proxies /api, /socket.io, /public to the api
```

The browser only ever talks to `127.0.0.1:5173`; the dev proxy mirrors Caddy in production, so cookies stay first party and there is no CORS in app code. Set `VITE_DEV_API_ORIGIN` if the api runs elsewhere.

A user with a known password for local testing (never in production):

```
pnpm --filter @crm/api dev:user -- agent@flare.local "Faith Chebet" agent 1001 "Flare-dev-2026!"
```

## API types

`src/lib/api/schema.d.ts` is generated, never edited:

```
pnpm openapi:export        # api → docs/openapi.json (needs the dev database)
pnpm openapi:types         # docs/openapi.json → apps/web/src/lib/api/schema.d.ts
```

Run both after changing any route schema. CI regenerates the types before building.

## Layout

```
src/
  app/            App (providers, router), AuthenticatedRuntime (socket, call events, idle logout), DevTools
  routes/         file based routes; _app.tsx is the authenticated guard, __root.tsx the shell root
  features/       one folder per backend module (calls/call-store.ts holds the popup state machine)
  components/     shared UI; components/brand has the vector mark and wordmark
  lib/
    api/          openapi-fetch client, ApiError, generated schema
    auth/         Better Auth client, me query, permission helpers
    socket/       typed Socket.IO client, useSocketEvent, room helpers
    format/       phone (via @crm/shared), money (KES), dates (Africa/Nairobi)
    forms.ts      zod resolver, server 422 → field errors
    theme.ts      dark default, light, system; data-theme on <html>
    idle.ts       55 min warning, 60 min sign-out
  styles/         tokens.css (docs/18), app.css (Tailwind theme mapping, base, utilities)
public/
  favicon.svg, brand/*.svg (vector), icon-*.png and og.png (generated by `pnpm --filter @crm/web icons`)
```

Rules: `docs/17-frontend-guidelines.md` and `docs/18-brand-and-design-brief.md`. Screens follow the design brief; nothing is designed ad hoc.
